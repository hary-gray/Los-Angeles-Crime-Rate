# **Los Angeles Crime Analysis (2020)**
This project analyzes the 2020 Los Angeles crime dataset sourced from Data.gov, utilizing Python libraries including Pandas, NumPy, and Matplotlib.

The primary objective is to identify high-crime geographic areas and determine the most prevalent types of offenses committed throughout the year.
